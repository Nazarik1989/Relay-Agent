# Учусь превращать разработку в контент

Сегодня собираю локального агента, который смотрит не только на код, но и на смысл рабочего дня.

- Хочу, чтобы git diff превращался в человеческий сюжет, а не в сухой технический отчет.
- Важный инсайт: контент уже есть внутри работы, его нужно не выдумывать, а внимательно доставать.
- Главная сложность MVP: не раскрыть приватные детали и не скатиться в жаргон для программистов.
- Потенциальный формат: рилс про AI-матрешку, где агент помогает строить агента, который будет рассказывать про агентов.
- Польза для обычного человека: такой же подход можно применить к заметкам, задачам, переговорам и рутине малого бизнеса.
